# TukTakMovies — Movie News Website + Admin Panel

এখন সাইটটার সাথে একটা **Admin Panel** (`/admin.html`) যোগ করা হয়েছে। এখন থেকে নতুন মুভি/রিভিউ/আর্টিকেল পোস্ট করতে কোনো কোড এডিট করা লাগবে না — ব্রাউজার থেকে লগইন করে ফর্ম পূরণ করলেই হবে। ডেটা জমা থাকে Cloudflare-এর নিজস্ব ডাটাবেজ **D1**-এ।

মোবাইলে হেডার ভেঙে যাওয়ার সমস্যাও ঠিক করা হয়েছে (টপবার এখন র‍্যাপ করে, ওভারল্যাপ করে না; ছোট স্ক্রিনে অপ্রয়োজনীয় লিংক/তারিখ লুকিয়ে যায়)।

## ফাইল স্ট্রাকচার
```
tuktakmovies/
├── public/                 → ওয়েবসাইটের সব স্ট্যাটিক ফাইল
│   ├── index.html          → হোমপেজ
│   ├── admin.html          → অ্যাডমিন প্যানেল (লগইন + পোস্ট ম্যানেজমেন্ট)
│   ├── css/style.css       → মূল সাইটের স্টাইল
│   ├── css/admin.css       → অ্যাডমিন প্যানেলের স্টাইল
│   ├── js/script.js        → হোমপেজ: API থেকে পোস্ট লোড করে দেখায়
│   └── js/admin.js         → অ্যাডমিন প্যানেলের লজিক
├── worker/index.js         → Cloudflare Worker: সাইট সার্ভ করে + /api/posts API চালায়
├── wrangler.toml           → Cloudflare কনফিগ (D1 বাইন্ডিং সহ)
├── schema.sql              → ডাটাবেজ টেবিলের স্ট্রাকচার
└── README.md
```

এখন থেকে এই সাইটটা আর শুধু "drag & drop" করে ডিপ্লয় করা যাবে না — কারণ এতে এখন একটা Worker + ডাটাবেজ আছে। এর জন্য একবার **Wrangler CLI** দিয়ে সেটআপ করতে হবে (নিচে ধাপে ধাপে দেওয়া আছে)। এরপর থেকে চাইলে GitHub দিয়ে অটো-ডিপ্লয়ও করতে পারবেন।

## এক নজরে সেটআপ ধাপ

### ১. দরকারি টুল ইনস্টল করুন
আপনার কম্পিউটারে [Node.js](https://nodejs.org) ইনস্টল থাকতে হবে। তারপর টার্মিনালে:
```bash
npm install -g wrangler
wrangler login
```
এটা ব্রাউজারে Cloudflare লগইন পেজ খুলবে — আপনার Cloudflare অ্যাকাউন্ট দিয়ে অনুমতি দিন।

### ২. প্রজেক্ট ফোল্ডারে যান
zip ফাইলটা এক্সট্র্যাক্ট করে তার ভেতরে ঢুকুন:
```bash
cd tuktakmovies
```

### ৩. D1 ডাটাবেজ তৈরি করুন
```bash
npx wrangler d1 create tuktakmovies-db
```
এই কমান্ড চালালে একটা `database_id` প্রিন্ট হবে। সেটা কপি করে `wrangler.toml` ফাইলে `database_id = "REPLACE_WITH_YOUR_DATABASE_ID"` — এই লাইনে বসিয়ে দিন।

### ৪. ডাটাবেজে টেবিল বানান
```bash
npx wrangler d1 execute tuktakmovies-db --remote --file=./schema.sql
```

### ৫. অ্যাডমিন পাসওয়ার্ড সেট করুন
```bash
npx wrangler secret put ADMIN_PASSWORD
```
এখানে যা টাইপ করবেন সেটাই হবে আপনার `/admin.html`-এ লগইন করার পাসওয়ার্ড। এটা কখনো কোডে লেখা থাকে না, Cloudflare-এ এনক্রিপ্টেড থাকে।

### ৬. ডিপ্লয় করুন
```bash
npx wrangler deploy
```
কমান্ড শেষ হলে একটা `*.workers.dev` লিংক দেখাবে — এটাই আপনার লাইভ সাইট।

## ব্যবহার করবেন কীভাবে
1. আপনার সাইটের `/admin.html` এ যান (যেমন `https://your-site.workers.dev/admin.html`)।
2. ধাপ ৫-এ সেট করা পাসওয়ার্ড দিয়ে লগইন করুন।
3. উপরের ফর্ম থেকে পোস্টের ধরন বেছে নিন:
   - **Featured** → হোমপেজের সবচেয়ে উপরের বড় হিরো ব্যানার (একসাথে একটাই দেখাবে, সবার আগে যেটা তৈরি হয়েছে সেটা)
   - **Movie Review** → "Latest Movie Reviews" সেকশনে যায়
   - **Movie** → "Latest Movies" সেকশনে যায়
   - **Article** → "Popular Articles" সেকশনে যায়
   - **Trending** → সাইডবারের "Trending Now" তে যায়
4. Title, ছবির লিংক (Image URL), রেটিং/স্কোর, তারিখ ইত্যাদি পূরণ করে **Save Post** চাপুন — সাথে সাথে হোমপেজে দেখা যাবে।
5. নিচের লিস্ট থেকে যেকোনো পোস্ট **Edit** বা **Delete** করতে পারবেন।

> ছবির জন্য: নিজের হোস্ট করা ছবির লিংক (ইমগুর, Cloudflare Images, আপনার নিজের সার্ভার ইত্যাদি) ব্যবহার করুন। কপিরাইট করা মুভি পোস্টার/স্টিল নিজের অনুমতি ছাড়া ব্যবহার না করাই ভালো।

## পরে কোনো আপডেট করলে
কোড বদলালে (যেমন ডিজাইন পরিবর্তন) আবার শুধু চালান:
```bash
npx wrangler deploy
```
পোস্ট যোগ/এডিট/ডিলিট করার জন্য আর কখনো ডিপ্লয় করা লাগবে না — সেটা `/admin.html` থেকেই সরাসরি হয়ে যায়।

## GitHub দিয়ে অটো-ডিপ্লয় (ঐচ্ছিক)
Cloudflare Dashboard → **Workers & Pages → Create → Connect to Git** থেকে এই রিপো কানেক্ট করলে কোড পুশ করলেই অটো-ডিপ্লয় হবে। তবে D1 বাইন্ডিং ও `ADMIN_PASSWORD` সিক্রেট প্রথমবার উপরের `wrangler` কমান্ড দিয়ে সেটআপ করতে হবে — এটা এক-বারের কাজ।

## এই আপডেটে কী কী ঠিক করা হলো
- **মোবাইল হেডার বাগ:** টপবার আগে ফিক্সড height-এ ছিল বলে তারিখ/লিংক wrap করলে হেডারের সাথে ওভারল্যাপ করত। এখন height auto + wrap হয়, ছোট স্ক্রিনে অপ্রয়োজনীয় জিনিস (তারিখ, About/Contact লিংক) লুকিয়ে যায়।
- **হিরো ব্যানারের placeholder ছবি:** আগের placeholder ছবির মধ্যে বড় করে টেক্সট বসানো ছিল যেটা এলোমেলো লাগছিল — এখন CSS দিয়ে বানানো একটা পরিষ্কার gradient ব্যবহার করা হয়েছে, আর Featured পোস্ট যোগ করলে আপনার নিজের ছবি সেখানে বসে যাবে।
- **কোড ছাড়া পোস্ট করা:** Admin Panel + D1 ডাটাবেজ যোগ করা হয়েছে, যাতে প্রতিটা পোস্টের জন্য আর কোড এডিট করতে না হয়।
